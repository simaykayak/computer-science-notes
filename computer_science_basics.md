# Computer Science Fundamentals
A discipline covering fundamental building blocks such as hardware, software, data structures, and algorithms.
It forms the foundation of all technology and software development fields by helping us understand how computers work, how data is processed, and how problems are solved.

## Hardware
The name given to all the physical, touchable parts of a computer. It provides the physical infrastructure necessary for software to run.
* Processor (CPU)
* Memory (RAM)
* Graphics Card (GPU)
* Storage Devices (SSD/HDD)
* Motherboard
* Keyboard and Mouse

## Software
The programs and instructions that tell the computer what to do.
It consists of two main groups:
System Software: Enables the computer to function.
* Windows
* Linux
* macOS
Application Software: Helps users perform specific tasks.
* Microsoft Word
* Google Chrome
* VS Code
* Photoshop

## CPU (Central Processing Unit)
The brain of the computer.
Executes instructions, processes data, and performs all calculations.
The processor's speed and core count affect system performance.

## GPU (Graphics Processing Unit)
A hardware unit that performs graphics processing.
Heavily used in gaming, video editing, and AI applications.
In some computers it's integrated into the processor, while in others it exists as a separate graphics card.

## RAM (Memory)
A temporary data storage area.
Operates quickly.
Stores data for open programs; its contents are erased when the computer is turned off.
Higher RAM capacity improves multitasking performance.

## Disk (Storage)
Disks store data permanently.
There are two types: HDD and SSD.
HDD: Slower and cheaper. Uses magnetic storage.
SSD: Faster and more durable. Uses flash memory. Preferred in modern computers.

## Motherboard
The main circuit board that connects all hardware components of a computer to each other.
The CPU, RAM, storage devices, and other hardware communicate through the motherboard.
It ensures all components are connected compatibly so the computer can function properly.

## Computer Memory Types
There are different types of memory in a computer.
RAM - Temporary memory
ROM - Permanent memory
Cache - Very fast intermediate memory
Each is used for different purposes.

## Cache Memory
A very fast type of memory located between the processor and RAM.
Temporarily stores frequently used data, allowing the processor to work faster.
It has different levels: L1, L2, L3.

## Operating System
Acts as a bridge between the user and the hardware.
Responsibilities: Memory management, File management, Running programs, Hardware control
* Windows
* Linux
* macOS

## Algorithm
A sequence of steps followed to solve a problem.
Every algorithm has an input and an output.
Choosing the right algorithm directly affects the speed and efficiency of a program.
Algorithms form the foundation of computer programs.

## Computer Networks
Computer networks are systems that allow devices to share data and communicate with each other.
Networks are classified into different types based on their coverage area.
* LAN (Local Area Network)
A local network covering a small area.
Commonly used in homes, schools, and offices.
Has a high data transfer speed.
* WAN (Wide Area Network)
A wide area network that connects multiple LAN networks together.
Enables communication between cities, countries, and continents.
The Internet is one of the largest examples of a WAN.
* Internet
The largest computer network in the world, connecting billions of devices to each other.
Allows users to share information, access websites, and benefit from online services.
Data is transmitted over the internet in packets.

## IP Address
A unique identification number assigned to each device on a network.
IPv4 addresses contain four octets, like 192.168.1.1.
IPv6 offers a much larger address space.
IP addresses allow data to be routed to the correct destination.

## Data Structures
Structures used to store and access data in an organized manner.
Choosing the right data structure greatly improves an algorithm's performance.
Most basic examples: array, linked list, stack, queue

## Database
Systems where data is stored in an organized and secure manner.
Enables large amounts of data to be managed in an organized way.
Provides fast access to data.
Managed using query languages such as SQL.
* PostgreSQL
* Oracle
* MySQL

## Programming Languages
Used to give instructions to a computer.
Many programming languages enable the development of software.
* C
* C++
* C#
* Python
* Java
* JavaScript

## Bit and Byte
Bit: The smallest unit of data a computer can process. Takes only the value 0 or 1.
File sizes and memory capacities are usually expressed in bytes and their multiples.

## Binary (Binary Number System)
Computers process all data using the binary number system.
In the binary system, only the digits 0 and 1 are used.

## Input and Output Devices
Hardware that allows the computer to communicate with the user.
* Input: Keyboard, Mouse, Microphone, Scanner
* Output: Monitor, Printer, Speaker, Projector

## File System
The structure that determines how files are organized on storage devices.
The operating system finds and manages files through this structure.

## Compiler and Interpreter
Programming languages are not directly understood by computers.
* Compiler: Translates the entire program into machine language and then runs it.
Example: C, C++
* Interpreter: Reads and executes the program line by line.
Example: Python, JavaScript

## Debugging
The process of finding and fixing errors within a program.
Main types: Syntax Error, Runtime Error, Logical Error

## IDE (Integrated Development Environment)
A development environment that makes writing code easier.
Usually includes these tools: Code editor, Compiler, Debugger, Terminal
Examples: VS Code, CLion

## Git and GitHub
Git: A version control system used in software projects.
GitHub: A platform that allows Git projects to be stored online and developed collaboratively as a team.
Basic Commands: git init, git add, git commit, git push
